How to connect it correctly

A simple flow without confusion between the website account and Telegram.

1. Sign in to the exact Med Tech account you want to connect

If the website is open under a doctor account, Telegram will connect to that doctor. If a patient account is open, it will connect to that patient.

2. Generate a code

The code is one-time and is used only to safely link the current website account to Telegram.

3. Open the bot with the button above

If a deep link is available, the code is passed automatically. This is the easiest and safest way.

4. Or send the code manually

{% if telegram_link_code %} Manual command: /link {{ telegram_link_code.code }} {% else %} Generate a code first, then send it in the format /link CODE. {% endif %}
